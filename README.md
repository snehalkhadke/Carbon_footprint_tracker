# 🌍 EcoTrack: Carbon Footprint & Sustainability Hub

Welcome to the **Carbon Footprint Tracker**, an interactive awareness platform designed to help you monitor, understand, and reduce your carbon emissions. Let's make the planet greener, one step at a time! 🌱

---

## ✨ Key Features

- **📊 Live City Emissions**: Monitor real-time atmospheric metrics (like Carbon Monoxide, PM2.5, NO2) for any city globally, utilizing Open-Meteo's powerful API. Includes a beautiful 72-hour historical trend chart.
- **🧮 Interactive Calculators**: Easily estimate the carbon output from your daily commute, energy usage, diet, and travel habits.
- **🤖 Gemini AI Sustainability Advisor**: A custom-built AI assistant powered by Google's Gemini models to provide personalized insights and suggest eco-friendly lifestyle changes.
- **🏆 Streak Badges & Achievements**: Gamified experience to keep you motivated. Unlock badges as you hit sustainability milestones.
- **🔐 Secure Authentication**: Integrated with Firebase Authentication for safe and secure access to your profile.
- **🌐 Atmosphere 3D & Live Ticker**: Visual representations and live data ticking to keep environmental awareness at the forefront.

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 19 + TypeScript ⚡
- **Build Tool**: Vite 🚀
- **Styling**: Tailwind CSS (v4) 🎨
- **Animations**: Motion (fka Framer Motion) 🎬
- **Charts & Data Viz**: Recharts 📈
- **Database & Auth**: Firebase / Firestore 🛡️
- **AI Integration**: Google Gen AI SDK (`@google/genai`) 🧠
- **Icons**: Lucide React 🧩

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Environment Configuration**:
   Ensure you have your environment variables set up (refer to `.env.example`).
   - `GEMINI_API_KEY`: Required for the AI advisor.
   - `VITE_FIREBASE_*`: Required for secure authentication.

3. **Start the Development Server**:
   ```bash
   npm run dev
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```
